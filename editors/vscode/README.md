# Moka Language Support for VS Code

Syntax highlighting, bracket matching, comment toggling, and auto-indentation for `.moka` files.

## Quick Install (Linux / macOS)

Create a symlink into VS Code's extensions folder:

```bash
ln -s /home/gianluca/Progetti/moka/editors/vscode ~/.vscode/extensions/moka-lang
```

Then reload VS Code (`Ctrl+Shift+P` -> **Developer: Reload Window**).

## Quick Install (Windows)

Copy or link `editors/vscode` into `%USERPROFILE%\.vscode\extensions\moka-lang` and reload VS Code.
